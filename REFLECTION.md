# Reflection

## 1. Can I explain what my code does?

The form collects user information through different input types including
text, radio buttons, checkboxes, a dropdown, a date picker, and a textarea.
The JavaScript validates each field when the user clicks Submit error messages are
displayed next to the fields that fail validation 

## 2. What was my coding process?

I started by building the HTML structure first, then moved to CSS styling,
and finally wrote the JavaScript validation. I worked on each part in its
own Git branch and committed after completing each feature. 

## 3. What challenges did I have?

The regex validation was challenging because I had to understand how patterns
work and how to apply them to an input field. Connecting the error messages
to the right input fields was also tricky at first. Understanding how
querySelectorAll works with radio buttons and checkboxes to check if any
option was selected took some time to figure out.

## 4. What would I do differently now?

I would commit more frequently after each small change instead of doing
multiple changes in one commit. I would also test each validation function
individually as I wrote it instead of testing everything at the end.
